# WattsFlow: Full Claude Code Prompt

انسخ البرومبت التالي كاملًا داخل Claude Code لبناء نظام WattsFlow.

```text
إذا لم يكن هناك مشروع جاهز، أنشئ مشروع Next.js جديد من الصفر داخل هذا المجلد وطبّق كل المتطلبات.

أريدك تبني لي نظام SaaS كامل وشامل باسم مؤقت: WattsFlow

اللغة:
- التطبيق يجب أن يدعم العربية والإنجليزية.
- العربية هي اللغة الافتراضية DEFAULT.
- الواجهة العربية تكون RTL.
- الواجهة الإنجليزية تكون LTR.
- أضف نظام i18n واضح ومنظم.
- لا تكتب النصوص مباشرة داخل المكونات إذا أمكن؛ استخدم ملفات ترجمة.
- وفر زر/قائمة لتغيير اللغة بين العربية والإنجليزية.
- احفظ تفضيل اللغة للمستخدم إن أمكن.

الفكرة:
نظام SaaS لإدارة ومتابعة عملاء واتساب للأنشطة الصغيرة مثل الصالونات، العيادات، مكاتب العقار، المدربين، ومقدمي الخدمات. الهدف أن يساعد صاحب النشاط على تنظيم العملاء، تصنيفهم، تذكير نفسه بالمتابعة، واستخدام قوالب رسائل جاهزة لفتح محادثات واتساب بسرعة.

المطلوب:
ابنِ تطبيق production-ready بأعلى معايير الجودة، الأمان، الأداء، قابلية التوسع، وتجربة المستخدم.

التقنيات المفضلة:
- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui أو مكونات UI نظيفة مشابهة
- Prisma ORM
- PostgreSQL
- NextAuth/Auth.js أو نظام Auth آمن
- Stripe للاشتراكات
- Zod للتحقق من البيانات
- React Hook Form للنماذج
- lucide-react للأيقونات
- next-intl أو حل i18n مناسب
- ESLint + Prettier
- Playwright أو Vitest للاختبارات حسب المناسب

إذا كان المشروع الحالي يستخدم تقنيات مختلفة، افحصه أولًا واتبع نمطه بدل إعادة بنائه من الصفر إلا إذا كان ذلك ضروريًا.

الميزات الأساسية:

1. المصادقة والحسابات
- تسجيل حساب جديد
- تسجيل دخول
- تسجيل خروج
- استعادة كلمة المرور إذا كانت البنية تسمح
- دعم تعدد الشركات/المساحات Workspace
- كل مستخدم ينتمي إلى Workspace
- لا يمكن لأي مستخدم رؤية بيانات Workspace آخر

2. لوحة التحكم الرئيسية
- عرض إحصائيات مختصرة:
  - عدد العملاء
  - العملاء الجدد هذا الأسبوع
  - المتابعات المتأخرة
  - العملاء في كل مرحلة
  - معدل التحويل التقريبي
- واجهة احترافية بسيطة ومناسبة لأصحاب الأنشطة الصغيرة
- لا تجعلها Landing Page، اجعل أول شاشة بعد الدخول هي لوحة العمل الفعلية

3. إدارة العملاء
- إنشاء عميل جديد
- تعديل عميل
- حذف/أرشفة عميل
- الحقول:
  - الاسم
  - رقم الجوال
  - البريد الإلكتروني اختياري
  - المصدر: Instagram, WhatsApp, Referral, Website, Walk-in, Other
  - المرحلة: New, Interested, Follow Up, Won, Lost
  - القيمة المتوقعة اختياري
  - ملاحظات
  - تاريخ آخر تواصل
  - تاريخ المتابعة القادمة
- البحث والفلترة حسب الاسم، الرقم، المرحلة، المصدر، والمتابعات المتأخرة

4. Kanban Pipeline
- لوحة Kanban للمراحل:
  - New
  - Interested
  - Follow Up
  - Won
  - Lost
- إمكانية نقل العميل بين المراحل بالسحب والإفلات إذا كان ذلك مناسبًا، أو بأزرار/قائمة تغيير المرحلة
- تحديث المرحلة في قاعدة البيانات
- تصميم واضح وسريع ومناسب للاستخدام اليومي

5. التذكيرات والمتابعات
- صفحة تعرض:
  - متابعات اليوم
  - متابعات متأخرة
  - متابعات قادمة
- إمكانية تحديد موعد متابعة للعميل
- إمكانية تعليم المتابعة كمكتملة
- سجل بسيط للتواصل مع العميل
- تنبيه بصري للمتابعات المتأخرة

6. قوالب الرسائل
- CRUD لقوالب رسائل واتساب
- القالب يحتوي:
  - العنوان
  - المحتوى
  - التصنيف: Welcome, Follow Up, Offer, Appointment, Closing, Other
- دعم متغيرات بسيطة مثل:
  - {{name}}
  - {{businessName}}
- عند اختيار قالب لعميل، يتم استبدال المتغيرات تلقائيًا
- زر يفتح واتساب برابط:
  https://wa.me/{phone}?text={encodedMessage}
- اهتم بتنسيق أرقام الجوال لتعمل مع wa.me

7. الاشتراكات والدفع
- دمج Stripe بشكل نظيف
- خطط:
  - Basic: 19 USD/month
  - Pro: 29 USD/month
  - Team: 49 USD/month
- اجعل هناك حدودًا مبدئية:
  - Basic: حتى 100 عميل
  - Pro: حتى 1000 عميل
  - Team: حتى 5000 عميل وعدة أعضاء
- صفحة Billing تعرض الخطة الحالية وحالة الاشتراك
- Webhook لتحديث حالة الاشتراك
- امنع استخدام الميزات المدفوعة إذا كان الاشتراك غير نشط
- إذا كانت مفاتيح Stripe غير موجودة في env، اجعل التطبيق يعمل بوضع development مع رسائل واضحة بدون كسر كامل النظام

8. إعدادات النشاط
- اسم النشاط التجاري
- نوع النشاط
- الدولة
- رمز الدولة الافتراضي للجوال
- توقيت العمل اختياري
- إعدادات بسيطة للرسائل

9. الأمان والصلاحيات
- تحقق من كل API Route أو Server Action
- لا تعتمد على الواجهة فقط في الحماية
- تأكد من أن كل استعلام في قاعدة البيانات مربوط بـ workspaceId
- استخدم Zod للتحقق من المدخلات
- امنع IDOR بين المستخدمين
- تعامل مع الأخطاء بدون تسريب معلومات حساسة
- لا تسجل أسرار أو Tokens في الكونسول

10. تجربة المستخدم
- واجهة عربية RTL افتراضيًا
- واجهة إنجليزية LTR
- النصوص متوفرة بالعربية والإنجليزية
- تصميم حديث وعملي
- مناسب للديسكتوب والجوال
- لا تستخدم ألوان كثيرة
- استخدم تباين واضح
- استخدم أيقونات lucide للأزرار
- لا تجعل الواجهة تسويقية؛ اجعلها أداة عمل حقيقية
- اهتم بالحالات:
  - Loading
  - Empty state
  - Error state
  - Success toast
  - Confirm delete

11. قاعدة البيانات
صمم Prisma schema بشكل احترافي يشمل على الأقل:
- User
- Account/Session إذا استخدمت NextAuth
- Workspace
- WorkspaceMember
- Customer
- MessageTemplate
- FollowUp
- InteractionLog
- Subscription
- AuditLog اختياري لكن مفضل

12. الاختبارات والجودة
- أضف اختبارات للأجزاء الحساسة:
  - صلاحيات الوصول للـ workspace
  - إنشاء عميل
  - تحديث مرحلة العميل
  - توليد رابط واتساب
  - حدود الاشتراك
  - اختيار اللغة الافتراضية العربية
  - اتجاه RTL للعربية و LTR للإنجليزية
- شغّل:
  - lint
  - typecheck
  - tests
  - build
- أصلح كل الأخطاء قبل الانتهاء

13. ملفات البيئة
أنشئ .env.example يحتوي على:
- DATABASE_URL
- NEXTAUTH_SECRET أو AUTH_SECRET
- NEXTAUTH_URL أو AUTH_URL
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET
- STRIPE_PRICE_BASIC
- STRIPE_PRICE_PRO
- STRIPE_PRICE_TEAM
- APP_URL

14. التوثيق
حدّث README.md واشرح بالعربية والإنجليزية:
- فكرة المشروع
- طريقة التشغيل المحلي
- إعداد قاعدة البيانات
- تشغيل migrations
- إعداد Stripe
- إعداد اللغات i18n
- أوامر الاختبار والبناء
- أهم القرارات التقنية
- ما الذي تم إنجازه
- ما الذي يحتاج إعداد خارجي

15. المطلوب منك أثناء التنفيذ
- افحص المشروع الحالي أولًا
- اشرح باختصار الخطة قبل التعديل
- نفّذ التغييرات فعليًا
- لا تترك TODOs مهمة
- لا تكسر الملفات الموجودة بدون سبب
- اتبع نمط المشروع الحالي
- إذا احتجت اختيارًا تقنيًا، اختر الخيار الأكثر استقرارًا وبساطة
- بعد الانتهاء، أعطني ملخصًا واضحًا:
  - الملفات التي تغيرت
  - الميزات التي تم بناؤها
  - الأوامر التي شغّلتها
  - نتائج الاختبارات
  - أي إعدادات مطلوبة مني

معايير القبول النهائية:
- التطبيق يعمل محليًا بدون أخطاء
- العربية هي اللغة الافتراضية
- يمكن تغيير اللغة إلى الإنجليزية
- اتجاه العربية RTL واتجاه الإنجليزية LTR
- المستخدم يستطيع التسجيل والدخول
- المستخدم يستطيع إنشاء Workspace
- المستخدم يستطيع إضافة العملاء وإدارتهم
- المستخدم يستطيع نقل العملاء بين المراحل
- المستخدم يستطيع إنشاء قوالب رسائل وفتح واتساب برسالة جاهزة
- المستخدم يستطيع رؤية المتابعات المتأخرة والقادمة
- بيانات كل Workspace معزولة تمامًا
- يوجد Billing structure جاهز لـ Stripe
- الواجهة عربية/إنجليزية واحترافية ومتجاوبة
- build ينجح
- typecheck ينجح
- lint ينجح
```
